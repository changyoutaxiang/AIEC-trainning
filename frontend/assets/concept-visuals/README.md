## 🎯 命名规范

### 核心哲学插图
**文件名**: `core-philosophy.svg`  
**对应内容**: 每个习惯的整体核心理念  
**显示位置**: "理念导入"页面顶部，核心哲学文字的配图

### 训练单元插图
**文件名格式**: `unit_{习惯号}_{单元号}.svg`  
**示例**:
- `unit_1_1.svg` → 习惯一的第1个训练单元
- `unit_1_2.svg` → 习惯一的第2个训练单元
- `unit_2_1.svg` → 习惯二的第1个训练单元

**对应内容**: 每个训练单元的具体理念  
**显示位置**: 每个训练单元理念卡片的配图

## 🎨 SVG设计建议

### 尺寸规范
- **推荐宽度**: 300-400px
- **推荐高度**: 200-300px
- **纵横比**: 4:3 或 3:2 较为理想
- **格式**: 矢量SVG，支持响应式缩放

### 设计风格
- **色彩**: 与系统主色调一致 (#007AFF蓝色系)
- **风格**: 简洁现代，Apple风格
- **元素**: 抽象几何图形、线条、渐变
- **避免**: 过于复杂的细节，文字内容

### 技术要求
- 使用相对单位 (%, em, rem)
- 避免绝对尺寸的硬编码
- 支持CSS样式覆盖
- 文件大小控制在50KB以内

## 🔄 工作流程

### 1. 渐进式添加
你可以逐个添加SVG文件，系统会自动检测：
- **有SVG**: 显示图文结合的丰富界面
- **无SVG**: 显示纯文字版本，不影响功能

### 2. 添加新SVG
1. 将SVG文件放入对应的习惯文件夹
2. 按命名规范重命名文件
3. 刷新浏览器页面，SVG自动加载

### 3. 测试验证
- 访问: http://localhost:8000/habit-learning.html?habit=1
- 进入"理念导入"模块
- 验证SVG是否正确显示

## 🛠️ 技术实现

### 自动检测逻辑
系统会自动检测SVG文件是否存在：
```javascript
// 检查文件是否存在
const svgExists = await checkSVGExists(`assets/concept-visuals/habit_${habitId}/core-philosophy.svg`);
if (svgExists) {
    // 显示SVG版本
} else {
    // 显示纯文字版本
}
```

### 响应式显示
- **桌面端**: SVG与文字并排显示
- **移动端**: SVG在文字上方居中显示
- **加载失败**: 优雅降级为纯文字模式

## 💡 使用提示

1. **优先级建议**: 先完成习惯1的所有SVG，因为它的内容最完整
2. **设计工具**: 推荐使用 Figma, Adobe Illustrator, 或 Sketch
3. **在线优化**: 使用 SVGOMG (https://jakearchibald.github.io/svgomg/) 优化文件大小
4. **预览工具**: 可以直接在浏览器中打开SVG文件预览效果
