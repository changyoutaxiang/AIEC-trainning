## ⚡ 快速启动指令

### 开发环境准备
```bash
# 1. 启动后端服务
cd backend && npm start

# 2. 启动前端服务（新窗口）
cd frontend && python -m http.server 8080
```

### 测试验证
```bash
# 验证数据加载
curl http://localhost:8080/content/scenarios.json

# 验证API服务
curl http://localhost:3000/api/health
```
