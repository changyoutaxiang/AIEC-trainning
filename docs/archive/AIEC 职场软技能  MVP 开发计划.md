### **职场软技能应用：MVP开发计划 (V1.0)**

**文档用途:** 本计划旨在为“职场软技能应用”的开发提供清晰、可执行的步骤。它遵循 MVP (Minimum Viable Product) 原则，确保我们能以最小的成本、最快的速度验证核心价值，并在此基础上迭代演进。

#### **第一阶段：核心循环验证 (Core Loop Validation)**

**目标：** 验证“场景练习 \+ AI 反馈”这一核心模式的有效性和用户接受度。

**开发内容：**

1. **用户认证系统 (User Authentication):**  
   * 实现简单的用户注册和登录功能。  
   * **技术建议:** 使用 Firebase Authentication。  
2. **极简技能列表页 (Simplified Skill List Page):**  
   * 创建一个页面，以列表形式展示 **技能线二：沟通与协作** 中的 5 个技能点。  
   * 每个列表项可点击，点击后进入对应的练习场景。  
   * **技术建议:** 使用 React 创建页面和组件。  
3. **核心练习场景：2.1 闭环响应 (Core Practice Scenario):**  
   * **场景描述:** 模拟一个即时通讯界面（如飞书），界面中显示来自上级的消息：“小王，把XX项目的最新进展同步给我。”  
   * **用户交互:** 提供一个文本输入框和“发送”按钮，供用户输入回复。  
   * **技术建议:** 使用 React 构建交互界面。  
4. **AI 教练反馈系统 (AI Coach System):**  
   * **触发:** 用户点击“发送”后，前端将用户输入的文本发送到后端。  
   * **后端逻辑:**  
     * 创建一个云函数（Cloud Function）。  
     * 该函数接收到用户答案后，构造一个包含“评分标准”和“用户答案”的 Prompt。  
     * 调用 Gemini API，将 Prompt 发送给 AI 模型。  
     * 接收 AI 返回的结构化反馈（包含评分、分析和建议）。  
   * **数据存储:** 将用户的答案、AI 的反馈、得分等信息，存储到 Firestore 数据库中。  
   * **技术建议:** 使用 Firebase Cloud Functions \+ Gemini API \+ Firestore。  
5. **反馈展示页 (Feedback Display Page):**  
   * 用户提交答案后，页面跳转或在当前页展示 AI 教练的反馈报告。  
   * 清晰地展示评分、各个维度的分析、改进建议以及“专家级”参考答案。  
   * **技术建议:** 使用 React 构建反馈展示组件。

**本阶段不做 (Out of Scope):**

* 完整的技能树可视化。  
* 经验值、等级、徽章等游戏化系统。  
* 导师干预功能。  
* 复杂的个人主页和团队视图。

#### **第二阶段：完善游戏化与内容 (Enhance Gamification & Content)**

**(在第一阶段成功验证后启动)**

**目标：** 提升用户粘性，丰富学习内容，构建完整的单人学习体验。

**开发内容：**

1. **上线完整技能树：** 将所有六条技能线、近30个技能点全部录入系统，并以可视化的技能树形式呈现。  
2. **引入游戏化机制：** 开发经验值（XP）、等级和成就徽章系统。  
3. **构建个人成长档案：** 开发个人主页，展示用户的等级、徽章和动态更新的能力雷达图。

#### **第三阶段：构建完整生态 (Build the Full Ecosystem)**

**(在第二阶段成功验证后启动)**

**目标：** 引入导师的人工干预，形成人机结合的混合培养模式。

**开发内容：**

1. **开发导师干预机制：** 实现“自动触发”、“学员求助”和“导师抽查”三种干预模式。  
2. **构建教练仪表盘：** 为您创建专属的后台管理界面，用于查看学员进度、处理“待辅导”项和发表导师评论。  
3. **上线团队能力视图：** 开发团队整体的能力热力图和成长报告。
