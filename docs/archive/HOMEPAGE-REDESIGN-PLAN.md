# 🏠 首页重构设计方案文档

## 📋 项目背景
- **当前问题**: 首页与"七个习惯"页面内容重复，缺乏独特价值
- **设计目标**: 将首页转变为"系统介绍与导航中心"
- **设计理念**: Apple风格的分区块布局，清晰的信息层次

## 🎯 设计方案总览

### **设计理念**
将首页从"功能重复页面"转变为"系统介绍与导航中心"，采用Apple风格的分区块布局，每个区块承担不同的信息传达和导航功能。

### 🏗️ **页面布局结构**

#### **1. Hero区域 - 系统介绍** 
```
┌─────────────────────────────────────────┐
│  AIEC 职场软技能培训系统                  │
│  AI时代的七个习惯 × 现代职场实战          │
│  [立即开始学习] [了解更多]               │
└─────────────────────────────────────────┘
```
- **视觉设计**: 渐变背景 + 大标题 + 副标题 + CTA按钮
- **功能**: 系统总体介绍，引导用户进入学习

#### **2. 我们的团队区域**
```
┌─────────────────────────────────────────┐
│           我们的团队                     │
│  ┌─────────┐      ┌─────────┐           │
│  │  团队    │      │  团队    │           │
│  │  照片1   │      │  照片2   │           │
│  └─────────┘      └─────────┘           │
│  团队介绍文字和理念...                   │
└─────────────────────────────────────────┘
```
- **布局**: 左右两张照片 + 下方介绍文字
- **风格**: 圆角卡片设计，配简洁说明

#### **3. 学习方式介绍区域**
```
┌─────────────────────────────────────────┐
│              学习方式                    │
│  ┌────────┐ ┌────────┐ ┌────────┐      │
│  │理论导入│ │导师采撷│ │场景练习│      │
│  │  🎓   │ │  👨‍🏫   │ │  🎯   │      │
│  └────────┘ └────────┘ └────────┘      │
│  ┌────────┐                           │
│  │应用难题│                           │
│  │  🧩   │                           │
│  └────────┘                           │
└─────────────────────────────────────────┘
```
- **设计**: 4个卡片式图标+标题 (修正：不是5个)
- **功能**: 说明系统的四种学习方式
- **视觉**: 每个方式配专属图标和简短说明

#### **4. 核心功能导航区域**
```
┌─────────────────────────────────────────┐
│               核心功能                   │
│  ┌─────────────┐  ┌─────────────┐       │
│  │   七个习惯   │  │   技能训练   │       │
│  │    💎       │  │    🎯       │       │
│  │  完整体系    │  │  敬请期待    │       │
│  │ [进入学习]   │  │ [即将推出]   │       │
│  └─────────────┘  └─────────────┘       │
└─────────────────────────────────────────┘
```
- **布局**: 左右两个大卡片
- **功能**: 
  - 七个习惯：显示完成状态，点击进入seven-habits.html
  - 技能训练：显示"即将推出"状态

#### **5. 成长点滴预览区域**
```
┌─────────────────────────────────────────┐
│               成长点滴                   │
│  📊 个人学习记录 | 🏆 成就徽章 | 📈 进度统计 │
│  ┌─────────────────────────────────────┐ │
│  │  "开始记录你的成长历程..."          │ │
│  │        [查看我的学习记录]            │ │
│  └─────────────────────────────────────┘ │
└─────────────────────────────────────────┘
```
- **设计**: 预览卡片形式
- **状态**: 显示"即将推出"，为未来功能预留空间

### 🎨 **视觉设计风格**

#### **色彩方案**
- **主色调**: 保持现有的Apple蓝 (#007AFF)
- **背景**: 浅灰色系 (#f2f2f7)
- **卡片**: 白色背景 + 轻微阴影
- **文字**: 深灰色层次 (#333, #666, #999)

#### **布局特点**
- **响应式网格**: 适配桌面和移动端
- **卡片式设计**: 每个功能区域独立卡片
- **间距统一**: 使用一致的边距和内边距
- **圆角元素**: 保持Apple风格圆角设计

### 🔄 **与现有页面的关系**

#### **功能分工明确化**
- **首页 (index.html)**: 系统介绍 + 功能导航
- **七个习惯页面 (seven-habits.html)**: 专注于习惯学习内容
- **技能训练页面 (skills.html)**: 专注于技能练习（待开发）

#### **导航逻辑优化**
```
首页 → 了解系统 → 选择学习路径
  ↓
七个习惯 → 选择具体习惯 → 进入学习
  ↓  
习惯学习页面 → 完整学习体验
```

### 📱 **移动端适配考虑**

- **垂直堆叠**: 移动端各区域垂直排列
- **触摸优化**: 按钮和卡片适合手指点击
- **图片适配**: 团队照片在小屏幕上合理缩放

### 🚀 **实现优先级**

1. **Phase 1**: Hero区域 + 核心功能导航（立即可用）
2. **Phase 2**: 学习方式介绍区域（展示系统特色）
3. **Phase 3**: 团队介绍区域（需要照片素材）
4. **Phase 4**: 成长点滴预览（为未来功能预留）

## ⚠️ **重要约束条件**

### **不破坏现有功能**
- 确保不影响七个习惯学习页面的完整功能
- 保持现有CSS类名和JavaScript函数的兼容性
- 维护现有的导航结构和用户认证逻辑

### **技术实现注意事项**
- 使用独立的CSS类名，避免与现有样式冲突
- 保持现有的utils.js和app.js引用
- 新增样式应该是增量的，不覆盖现有样式
