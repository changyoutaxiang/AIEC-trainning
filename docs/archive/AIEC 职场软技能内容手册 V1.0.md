### **职场软技能应用：内容手册 (V1.0)**

**文档用途:** 本手册是"职场软技能应用"的核心内容库，定义了应用中所有的学习单元（技能线、技能点）及其对应的练习场景。在开发过程中，本手册将作为内容输入的唯一依据。

**核心框架:** 内容体系以"高效能人士的七个习惯"为底层逻辑，深度融合了 AIEC 团队独特的组织心法与实战经验，旨在成为每一位新伙伴职业成长的"导航系统"和"能力健身房"。

#### **技能线一：职业素养与心态 (Professionalism & Mindset)**

*这是职场身份的基石，也是践行 AIEC"价值交换"契约的个人起点。*

| 技能点 (Skill Point) | 经典练习场景 (Classic Scenario) |
| :---- | :---- |
| **1.1 责任感 (Ownership)** | 你发现昨天提供给同事的数据中有一个小错误，而TA已经基于此错误数据开始工作了。**你该怎么办？** |
| **1.2 积极主动 (Proactiveness)** | 你提前完成了本周的核心任务，还有半天工作时间。**你会如何利用这段时间，为团队的"场景库"或"知识库"做贡献？** |
| **1.3 拥抱不确定性** | 公司战略调整，你负责的项目优先级被降低，需要暂缓。你感到有些沮丧。**你会如何调整心态，并思考"新的变化带来了什么新机会？"** |
| **1.4 诚信第一 (Integrity First)** | 领导问你一个项目的进度，你预感可能无法按时完成，内心很焦虑。**你会选择"能力折扣"还是"信用折扣"？请模拟你的回答。** |
| **1.5 保持兴奋 (Maintaining Excitement)** | 你发现任务越积越多，时间永远不够用，感到了巨大的压力和挫败感。**请思考，如何通过调整认知（例如成长思维、理解趋势），让自己摆脱"气馁"或"摆烂"的状态，重新变得兴奋起来？** |

#### **技能线二：沟通与协作 (Communication & Collaboration)**

*核心是践行"有回应"四层次，将自己打造成一个透明、可靠、值得信赖的协作节点。*

| 技能点 (Skill Point) | 经典练习场景 (Classic Scenario) |
| :---- | :---- |
| **2.1 【核心】闭环响应 (Responsive Loop)** | 领导在群里@你："小王，把XX项目的最新进展同步给我。" **请用"有回应"四层次，完整模拟你在此后24小时内的所有沟通动作。** |
| **2.2 主动澄清 (Active Clarification)** | 业务方提出需求："我想要一个AI工具，能帮我们提高效率。" **请使用 5W1H 工具箱，提出至少三个关键问题以澄清真实需求。** |
| **2.3 向上沟通 (Communicating Up)** | 你负责的项目可能会延期两天。**你准备何时、以何种方式向你的直属领导汇报这个情况？（请体现对"WHY"的思考）** |
| **2.4 双赢思维 (Win-Win Mindset)** | 你需要另一个团队的资深工程师协助你解决一个棘手问题，但你知道他们团队的资源也非常紧张。**你会如何提出你的请求，让对方愿意帮助你？** |
| **2.5 统合综效 (Synergy in Action)** | 在一次头脑风暴会议中，团队成员提出了两个截然相反的技术方案，讨论陷入僵局。**你会如何引导讨论，尝试找到一个融合两者优点的新方案？** |

#### **技能线三：任务与时间管理 (Task & Time Management)**

*核心是掌握在"时间永远不够用"的现实中做出正确选择的智慧，并用"机制"战胜不稳定的"意愿"。*

| 技能点 (Skill Point) | 经典练习场景 (Classic Scenario) |
| :---- | :---- |
| **3.1 任务分解 (Task Decomposition)** | 领导交给你一个任务："调研并评估三款主流的开源大模型"。**你会如何将这个任务拆解成更小的、可执行的步骤？** |
| **3.2 优先级排序 (Prioritization)** | 你手头有5个任务，但预估只有时间完成3个。**你会如何通过与上级"对齐"，来判断哪些任务是真正重要的，并做出你的选择？** |
| **3.3 【核心】机制化工作 (Mechanism Design)** | 你发现团队每周都需要手动整理一份数据周报，流程繁琐且容易出错。**请设计一个简单的"机制"（一个SOP或自动化流程思路）来优化这件事。** |
| **3.4 过程同步 (Process Sync)** | 你正在做一个预计需要一周才能完成的任务。**你会选择在哪些关键节点，通过日报/周报等"制度化沟通"方式，主动同步进度？** |
| **3.5 直面魔鬼 (Facing Demons)** | 你接手了一个庞大而复杂的项目，感到无从下手，甚至有些恐惧。**你会如何运用"看细节"的原则，将这个"魔鬼"拆解成一个个你可以处理的小部分，从而克服恐惧？** |

#### **技能线四：问题解决与思考 (Problem Solving & Thinking)**

*这是将技术能力转化为商业价值的桥梁，学会结构化地拆解问题，并驾驭 AI 成为你最强大的"外脑"。*

| 技能点 (Skill Point) | 经典练习场景 (Classic Scenario) |
| :---- | :---- |
| **4.1 定义问题 (Defining the Problem)** | 业务方反馈："用户最近的活跃度下降了"。**这是一个现象而非问题，你会如何通过数据和沟通，去界定真正的问题所在？** |
| **4.2 结构化思考 (Structured Thinking)** | 针对"如何提升AI工具在销售团队的渗透率"这一议题，**请尝试用"技能、工具、场景"的思路来构建你的分析框架。** |
| **4.3 AI赋能思考 (AI-Empowered Thinking)** | 你需要让AI帮你完成一项复杂的规划任务。**你会如何进行"上下文工程"，为AI提供足够饱和且高效的背景信息，以确保它能给出高质量的输出？** |
| **4.4 目标导向 (Goal-Oriented)** | 领导让你负责一个新项目的技术预研，在开始之前，**你会先澄清哪些关于项目"最终目标"和"成功标准"的问题？** |

#### **技能线五：影响力与价值呈现 (Influence & Value Presentation)**

*让你的工作被看见、被理解、被认可，完成从"交付任务"到"创造价值"的关键跃迁。*

| 技能点 (Skill Point) | 经典练习场景 (Classic Scenario) |
| :---- | :---- |
| **5.1 理解他人诉求 (Understanding Stakeholders)** | 在启动一个内部工具项目前，你需要说服产品、运营和法务部门的支持。**请分别思考这三个部门的核心诉求和担忧可能是什么？** |
| **5.2 价值呈现 (Value Presentation)** | 你用AI技术将某个报告的生成效率提升了5倍。**在周会上，你将如何用1分钟时间，清晰地展示你的工作成果和"可复用的知识/方案"？（参考"有回应"第四层次）** |
| **5.3 建立信任 (Building Trust)** | 你作为AI BP，刚开始与一个新的业务团队合作。**你会采取哪三个具体行动，来快速建立他们对你的专业信任？** |

#### **技能线六：持续成长 (Continuous Growth)**

*践行 AIEC 成长四支柱，将个人成长与组织进化深度绑定，驱动自我实现的飞轮。*

| 技能点 (Skill Point) | 经典练习场景 (Classic Scenario) |
| :---- | :---- |
| **6.1 复盘与反思 (Review & Reflection)** | 你刚刚完成了一个"责任项目"，但结果并不理想。**你会如何克服"不想揭伤疤"的人性，直面差距，并从复盘中提炼出成长的养料？** |
| **6.2 同伴学习 (Peer Learning)** | 你在工作中发现了一个非常好用的 Prompt 技巧。**你会如何在一个小范围内发起分享，把它变成团队的公共知识？** |
| **6.3 有效辅导 (Effective Coaching)** | 你在一个技术难题上卡了很久，准备向资深同事请教。**为了让这次"辅导"最高效，你会提前做哪些准备？（带着问题？带着方案？）** |
| **6.4 【核心】精力管理 (Energy Management)** | 你感觉自己最近效率低下，身心俱疲。**请分别从体能、情绪、注意力和意义感四个层次，思考并设计一套属于你自己的精力恢复方案。** |
| **6.5 聪明的自驱 (Smart Self-Motivation)** | 领导即将出差，你预知自己会不可避免地松懈下来。**请设计一个"外驱"机制（例如公开承诺、结对学习、自动化提醒等），来"套路"自己，保持勇猛精进的状态。** |
